打开 GitHub 编辑页 / Open GitHub Editor ↗

发布步骤 / Publishing Steps

  1. 填写中英文标题、简介和正文；每段之间留空行。
    Enter bilingual title, summary and body; separate paragraphs with blank lines.
  2. 点击“生成并复制 JSON”。页面会把新文章加入现有资料，并复制完整文件。
    Click Generate and Copy JSON. It appends your article and copies the full file.
  3. 打开 GitHub 编辑页，选择全部现有内容并粘贴，再点击 Commit changes。
    Open the GitHub editor, replace the existing file with the copied JSON, then commit.
  4. 如需图片，先把图片上传至仓库的 assets/，再填写 assets/文件名。
    For images, upload to assets/ first and use its relative path.

建议先下载备份。GitHub Pages 发布需要片刻；刷新首页查看新文章。
Download a backup before committing. Give GitHub Pages a moment, then refresh the home page.
