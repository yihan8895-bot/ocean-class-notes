AI 使用与核验 / AI Use and Verification

本站公开说明 AI 在资料整理中的角色、可确认的模型信息、科学结果的复核办法，以及资料和图片的使用边界。记录日期：2026 年 11 月 5 日。

This page discloses AI's role in preparing the material, the model information that can be confirmed, ways to check scientific results, and limits on reusing sources and images. Record date: 5 November 2026.

AI / TOOL

OpenAI Codex 辅助文字、代码与页面制作。

OpenAI Codex assisted with writing, code and page construction.

MODEL / VERSION

本次披露页使用 GPT-6；历史页面的精确模型版本未完整留档。

This disclosure update used GPT-6; exact model versions for earlier pages were not fully logged.

STATUS / LIMIT

AI 输出不是原始观测，也不是未经复核即可引用的科学证据。

AI output is neither an original observation nor scientific evidence ready to cite without checking.

“AI-assisted” describes draft or implementation work. It does not mean every number, image or explanation came directly from a model, nor that this site trained an ocean-prediction model. The site maintainer still needs to review the work before course submission or formal citation.

模型记录与验证边界Model record and validation limits

可确认的记录是：本次说明页由 OpenAI Codex（GPT-6）辅助制作。此前网页多次迭代的模型 ID、参数设置、提示词和逐页生成日志未完整保存，因此不能可靠地给每一页指定同一模型。本站未对 GPT-6 做独立基准测试；模型名称本身不能证明海洋学内容准确。

The confirmed record is that OpenAI Codex (GPT-6) assisted with this disclosure update. Model IDs, settings, prompts and page-level generation logs for earlier iterations were not fully retained, so one model cannot reliably be assigned to every page. This site has not independently benchmarked GPT-6; naming a model does not validate the oceanography.

EOF 是经验正交分解的统计方法，不是大语言模型；模态解释方差不等于预测准确率或物理成因。海洋热浪识别、TEOS-10 物性计算和地转流公式也各有输入与适用条件。相关限制已在各专题页说明。

EOF is a statistical decomposition, not a language model. Explained variance is neither predictive accuracy nor proof of a physical cause. Marine-heatwave detection, TEOS-10 property calculations and geostrophic equations each have inputs and validity conditions, described in their topic pages.
